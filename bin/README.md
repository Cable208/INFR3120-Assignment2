
# INFR3120 – Assignment 2: Express Portfolio

## Project Overview
This is my personal portfolio website built for INFR3120 – Web and Scripting Programming at Ontario Tech University.

The website uses Node.js, Express.js, EJS, Bootstrap, and Font Awesome.

## Live Website
https://infr3120-assignment2-klh0.onrender.com/

## Features
- Home page with personal introduction
- About Me page with profile photo and introduction video
- Projects page featuring seven IT projects
- Contact page with form validation
- Responsive navigation bar and shared footer
- Express routes and reusable EJS templates

## Technologies
- Node.js
- Express.js
- EJS
- Bootstrap
- Font Awesome
- HTML and CSS
- JavaScript

## Running the Project Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Start the server:

   npm start

5. Open http://localhost:3000

## Project Structure
- routes/index.js – Routes for the four pages
- views/ – EJS templates
- views/partials/ – Shared header and footer
- public/ – CSS, images, videos and client-side assets
- app.js – Express application configuration
- bin/www – Server startup configuration

## Deployment
The website is deployed using Render and connected to GitHub.
